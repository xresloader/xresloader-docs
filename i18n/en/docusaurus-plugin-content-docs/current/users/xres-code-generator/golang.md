# Go integration {#golang集成指南}

The current Go integration depends on code generated by an additional plugin. A standalone tool, template module and complete guide have not yet been extracted.

See the [atsf4g-go](https://github.com/atframework/atsf4g-go) project for existing examples and usable versions:

- Templates: [src/template/config_set.go.mako](https://github.com/atframework/atsf4g-go/blob/main/src/template/config_set.go.mako) 和 [src/template/config_group.go.mako](https://github.com/atframework/atsf4g-go/blob/main/src/template/config_group.go.mako)
- protoc plugin: [protoc-gen-mutable](https://github.com/atframework/atsf4g-go/tree/main/atframework/atframe-utils-go/protoc-gen-mutable)
