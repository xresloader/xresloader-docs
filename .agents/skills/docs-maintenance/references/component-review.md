# 组件升级与截图核验

适用于同时更新 xresloader、xresconv-cli、xresconv-gui 的文档与示例。仅修改普通文字时无需整套执行；版本升级、迁移合同或截图更新时按相关项读取。2026-10 的实际证据见 [更新记录](../../../../docs/ai/component-refresh-2026-10.md)。

## 版本与行为

1. 分别核对正式 release/tag、上游 HEAD、构建配置和二进制自报版本。可执行文件名不能证明版本；本地开发包与最新正式版有差距时记录差距，截图使用目标版本的完整介质。
2. 读取迁移文档、命令解析、配置合并、调用 Schema 和实际调用方。帮助里的默认值与初始化代码冲突时追溯默认和重置路径，再做能区分行为的运行检查。
3. CLI 与 GUI 共享 XML，不保证所有运行语义相同。核对 work_dir / include 的基准、重复文件与深度、数组重新分组、数据版本、脚本执行、取消和结果确认；不要把一方的行为推广到另一方。
4. 构建、版本查询、预览、真实转换分别记录。批次退出码和已提交数不能证明逐条成功；对入门样例检查每个目标文件的 header、记录数和内容，必要时与直接 JAR 调用比较。

## 入门样例

快速上手要求 Java、JAR、一种批量工具和准备好的配置，并包含简短的数据核对及实际加载方法；descriptor 已提供时不增加 protoc 安装步骤。协议工具链、完整加载代码和扩展放在参考页，并从入门页链接。

版本更新前对照 Git 基线建立示例保留清单。修正过时命令、配置与脚本，必要时移入详细参考页并保留入口，不因缩短篇幅删除能力介绍、配置注释、可选项或样例文件。首页保留组件用途、仓库与下载；GUI / CLI 均为批量转表工具，dump-bin 用于查看已导出的二进制数据。

下载入口持续指向最新正式版，不在公开下载页写死版本、固定 tag 或带版本号的 latest/download 文件名。相同目标的下载链接只保留一条，不以平台、架构或包格式标签重复呈现。当前共享目录每组件提供一个 releases/latest 入口，包与摘要在发布页选择；本站不检测平台或筛选架构。latest API 仅查询版本与确认无正式版时的源码入口，404 提供当前 main 源码；首次发布后恢复 latest，403/网络错误不能宣称没有发布。修改后运行 npm run check:downloads，并用浏览器验证单一入口、页面打开后上游更新、首次发布、无 JS 和失败回退。布局覆盖 3840、2560、1920 与手机窄屏，既检查溢出，也检查宽屏是否实际扩展。

当前示例源在 [source/sample/current](../../../../source/sample/current/)，Excel 从 tables.json 生成，descriptor 从 kind.proto 生成；生成入口在 [scripts](../../../../scripts/)。历史 sample 可能依赖额外校验器或复杂扩展，先追溯依赖，不通过忽略校验来让演示成功。

下载 ZIP 要在全新临时目录解压、补入 JAR 并运行，不能让此前试验留下的文件掩盖缺失依赖。复核压缩包成员与公开页面的名称、命令和输出相符。

## 截图与界面

- 使用完整发行介质与独立示例目录，通过真实窗口操作采集。官方资产有摘要时先校验；记录版本、平台、运行时、输入配置、图片与采集方法。驱动应匹配实际系统 WebView。
- 浏览器适配器与 native RPC 的接口可能不同。先读取页面控件、接口 Schema 和已有测试，不猜测桥接方法名；原生字体权限等行为必须单独验证，不能用浏览器 mock 代替。
- 截图中的成功日志必须来自真实运行。对终端文本生成排版图时，明确标为“实际输出快照”，说明路径缩写等展示处理；不把它写成真实终端窗口截图。
- CLI 图采用足够字号和至少两倍像素密度，裁掉无内容的留白，不拉伸低分辨率旧图。核对实际展示尺寸中的文字，提供原图入口；窄屏可局部滚动，不能把整幅图缩得无法阅读。原始诊断和数值保留，节选须标明范围，不能重写成功日志。
- 新图优先采用可审查的 SVG、Mermaid 或既有绘图源；同时核对职责、连线和实际渲染。截图更新后检查本站桌面与窄屏、亮暗主题、图片加载、导航、键盘和搜索。

## 交付边界

维护上游文档不授权改上游实现或运行真实项目的原始输出、事件脚本。保留上游与本站已有修改，输出和采集日志隔离。按需同步来源索引和任务记录，不把普通组件升级计为 AI 初始化或等预算 Skill 对照实验已通过。
