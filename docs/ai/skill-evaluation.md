## 真实路由与产物实验

在同客户端、模型、工具、版本和预算的独立环境运行；保存发现路径、实际 Skill 调用事件、误触发/漏触发和错误类别。文件存在或 prompt-input 元数据命中只证明发现，模型的路由自述不算调用。可自动化断言检查输出；主观质量需要时人工盲评。

从五个代表任务比较启用 Skill 与未启用/旧版；新写与润色分别比较：

- T01 文档版本纠错：给相同原始页面和上游依据，检查参数准确、版本边界、示例、引用及站点构建；无法运行上游示例不得称已验证。
- T02 窄屏首页缺陷：给相同页面/CSS 和复现条件，检查改前/改后视觉行为、构建、改动范围；无浏览器证据不计视觉通过。
- T03 初始化遗漏回放：给同一完整初始化输入和干净仓库，检查整章、子项、已有规则、迁移资源及缺少可选工具时的替代流程，逐项计数并核对实际正文。
- T04 说明新写：给相同假设材料，包括总尝试 3 次含首次调用、明确版本下限和“构建通过但示例未运行”，检查是否保留数量、比较方向、前提及验证范围，能否让读者找到行动；不得新增工具参数或检查结果。
- T05 原稿润色：给相同中文作者复盘和英文接口说明，包含第一人称判断、真实排除/转折/递进、已定义术语及标识符，检查是否改善重复与指代，保护两项事实、作者声音和技术含义。人工随机顺序评审，记录偏好/持平、理由与返工成本；流畅度不能抵消语义退化。

记录产物正确性、实际耗时/token、权限拒绝与副作用边界。失败按发现、选择、流程、环境、资料和执行权限分类；重要流程加恶意输入及拒绝案例。升级模型/harness 后重新检查旧规则收益，不声称提示词保证绝不遗漏。
