# 操作、秘密与部署边界

## 命令预算和恢复

工具等待窗口、子进程超时和任务总截止分别设置；返回 session ID 或仍在运行只表示继续等待。先参考实际 CI/历史耗时与风险分配有限预算，不为所有任务固定 10–30 分钟。保留脱敏日志，超时检查下载、死锁、资源限制和旧进程状态，再决定重试。

只重试可能恢复的错误，初次失败后至多两次适当退避并加抖动，遵守 `Retry-After`；参数/解析错误与权限拒绝先定位。平台启动失败走平台允许的权限重试，不降低安全设置。写操作可能已成功，先查状态或幂等键/去重，再决定重放；不能盲重试部署、创建或发送。

自动化关闭交互与全量环境转储。登录交给用户受控界面，不通过模型收集秘密。持续预览/监听使用回环地址，记录本任务 PID、端口、日志和退出；停止只针对拥有的进程树，不能按名称杀共享服务。Windows 后台 `Start-Process` 使用 `-WindowStyle Hidden`。

## 临时产物与秘密

本仓库 `build/`、`.docusaurus/` 是既有生成目录；一次性脚本与日志用系统安全临时目录并记录精确路径，不混进待部署 `build/`。清理先解析绝对路径及链接目标，只删除本任务创建且核验在目标目录内的内容，保留必要证据与用户文件；不跨 shell 拼接递归删除命令。

当前无本地秘密目录或 `.env` 合同，不创建占位秘密布局。确实需要时先配置忽略与访问权限，提交无真实值的 `.env.example`，由用户/秘密管理器注入。秘密目录名、jq/yq 或提示词不构成安全保护；优先秘密管理器、系统凭据或受控进程环境。凭据不进模型上下文、参数、普通产物、日志或无关服务；避免 tracing、含秘密错误回显及全量配置读取。

CI 改动优先短期凭据与最小权限，第三方 Actions 固定完整 commit SHA；不可信 PR 与持秘密发布任务分离。当前 `.github/workflows/main.yml` 仍使用 tag、部署 SSH key、关闭主机校验及 force-push，这些是既有配置，不是推荐模板。本次不执行发布或扩展 CI 安全改造；后续发布维护须核验并提交具体改造，不把文档规则称为执行层安全保证。

## 部署准备和验收

当前 `main` push 工作流构建并向 GitHub/Gitee 的 `xresloader-docs-website` main 分支发布，包含 force-push；运行本地 `npm run deploy` 也可能产生外部写入。本次维护不授权触发这些动作。准备部署先交付可审阅制品和步骤，再按现有授权处理实际发布。

准备记录目标环境、源 commit 与制品校验/标识、Node/包管理版本、域名/baseUrl、CNAME/.nojekyll、路由与搜索健康检查和恢复上个已验证制品的条件。若涉及迁移，明确顺序、兼容窗口及失败恢复。核验预览、预发布与生产分别留证据，HTTP 200 之外检查首页、目标文档、资源及搜索；本地/mock 通过不能写为生产成功。

## MCP 接入

仓库无 MCP 客户端/服务端配置，本次未接入。当前 harness 的连接能力不属于仓库安装合同；常规事实查询使用已授权只读工具/官方 API 或 CLI 即可。无需为清空覆盖表创建 MCP 文件。

如果任务确实需要接入：记录服务来源、数据流、工具集、路径/读写范围、客户端/服务端/SDK/传输/协议版本，按实际版本核验后使用或迁移。官方 versioning 页本次为 2026-07-28；不能据此断言现有 SDK 实现了该版或迁移所有服务。

- 最小工具集、路径及权限；秘密只经预期通道注入，配置模板可入库，真实 token/cookie/会话不可入库或进入上下文。
- HTTP 依对应规范校验 OAuth audience、issuer、授权发现与 redirect，禁止 token passthrough；STDIO 用受控进程环境凭据，不套 HTTP OAuth。
- 显式业务状态句柄需不可预测、绑定主体并逐次授权，不能作为身份证明；无状态协议不代表业务无状态。
- HTTP 校验 Origin、限制监听并配置认证；STDIO stdout 仅协议、诊断写 stderr。单次取消优先用对应版本协议机制，服务退出只清理本任务拥有进程树。
- 校验输入、解析路径和链接、出站目标；防路径穿越、SSRF、工具元数据投毒及返回内容提示注入。工具 annotations 是提示信息，不能独立授予授权。
- 调用超时、输出上限、速率限制、脱敏审计及写权限落实到执行层；本地说明不能代替真实权限/超时测试。
